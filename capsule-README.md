# synthetic-players-capsule — public reproduction capsule

**What this is.** The complete, self-contained reproduction capsule for
the *Synthetic Players* research program (five phases of prospectively
registered LLM game-theory experiments): the append-only event store
(every recorded LLM request/response event for all phases), the sealed
registries, seal records and freeze packets, the claims ledger and
adjudication records, the adjudication and analysis code with a pinned
environment, SHA256SUMS with OpenTimestamps proofs, and a one-command
zero-credential verifier that replays the recorded runs byte-exactly.

**What this is not.** It contains no API keys, no personal data, and no
live-call capability requirement: the verifier never contacts a model
provider.

## Verify (one command, zero credentials)

```bash
./verify.sh
```

This checks the capsule-wide sha256 manifest, stages the event store,
strips provider variables from the environment, and runs the byte-exact
replay audits (Phase 4: 2,864/2,864 observations; Phase 5 audit —
request-body shas, parsed actions, rng draw profiles). Expect
`CAPSULE VERIFICATION PASS`.

Timestamp proofs: `verify/SHA256SUMS-final.txt.ots` can be checked with
`ots verify` (OpenTimestamps) against the Bitcoin blockchain once the
attestation is upgraded; `docs/phase5-close/` records the seal
chronology.

## Relationship to the private working repository

This capsule was generated by committed script
(`scripts/build-capsule.sh`) from the private working repo
`yoheinakajima/synthetic-players` at a recorded commit. It is a **fresh
history** — not a mirror: the working repo's full commit chronology
(including the sealed pre-registration commits) remains private until
the coordinated release. The chronology claims in the documents are
backed here by the OTS proofs rather than by git history.

## Coordinated-release plan

The private working repository flips public together with the paper
preprint (drop-day runbook committed there). Until then, this capsule
is the public verification surface: everything needed to check that
the recorded data, the sealed predicates, and the adjudicated verdicts
are internally consistent is in this repository.

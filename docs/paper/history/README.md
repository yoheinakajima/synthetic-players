## Why these files exist

The project uses additive correction rather than silent historical rewriting. Earlier drafts remain available so reviewers can verify:

- which claims changed;
- whether a result was demoted, removed, or reframed;
- when new analyses entered the record;
- how external criticism altered the living manuscript without changing sealed experimental artifacts.

The current paper’s correction ledger is in Appendix A of [`../paper-draft.md`](../paper-draft.md). The review chronology and role disclosures are under [`../../reviews/`](../../reviews/).

The v2 and v3 files were imported byte-exact from the manuscripts supplied for those review rounds and verified against pinned SHA-256 digests during GitHub Actions materialization.

\subsection{1. Scope and immutable
archive}\label{scope-and-immutable-archive}

The data are synthetic model decisions and procedural records from the
historical study, not a new human sample. Readable instructions below
retain all template fields; exact byte files are
\texttt{evidence/registry.json} and \texttt{evidence/personas-v4.json},
copied from source commit
\nolinkurl{62ab90beff1d291b069c87f13b6b6b3495171ddd}. No prompt was
regenerated. The sealed arm and schedule files define numeric bindings,
seed lanes, horizons, role/display mappings, and permitted replacements;
their immutable URLs and hashes are in \texttt{evidence-manifest.json}.

The confirmatory boundary is 320 Phase 3/X1 LLM runs +20 deterministic
baselines +2,864 Phase 4 +1,712 Phase 5 =4,916. Three completed legacy
diagnostics are also replayed: 4,919 verifier runs, comprising 4,899 LLM
runs +20 baselines. A run is an episode, not a call or a human subject.
The full event store's 5,505 completed runs, 54,276 round events,
108,552 seat-round choices, and 36,251 request events have a broader
boundary. The separate Phase 4--5 budget ledger records 30,530 calls,
13,141,675 input tokens, and 45,247 output tokens. Normal
request/response events (30,421/30,397) exclude other accounting
classes; twenty-four failed-run partials have no completed observation.
See immutable count reconciliation, not an equation between differently
scoped totals.

\subsection{2. Data dictionary and file
roles}\label{data-dictionary-and-file-roles}

\texttt{capsule/data/engine.db.xz} decompresses to the archived SQLite
graph/event store; \texttt{budget.db.xz} is the transactional call/token
ledger. Event \texttt{type} distinguishes requested, responded, parsed,
round, completed, and invalidation records. \texttt{run\_id} joins an
episode; payloads identify arm, prompt, persona, model, temperature,
seed, seat, round, attempt, raw completion, parser outcome, provenance
hashes, and RNG draws where recorded. Points are game payoff units.
Cooperation is a payoff-role choice, distinct from the displayed
COOPERATE token when labels are swapped. Episode mean is \{0,.5,1\};
proportions are unit-scale. Provider-failure partials never become
decoded actions. Definitions vary by historical phase and are not
backfilled.

CSV and JSON analysis exports under \texttt{docs/analysis/submission/}
carry condition/prompt labels, intervals, family audits, and prior
sensitivity. Figures are author-generated from these outputs.
Codebook/estimands: hierarchy and count reconciliation; complete
evidence inventory: supplied manifest. No provider API endpoint is
required to read the SQLite/JSON/CSV archive or replay it.

\subsection{3. Reproduction
instructions}\label{reproduction-instructions}

Use an isolated non-iCloud clone at the immutable commit. Review the
verifier before running it. The historical \texttt{capsule/verify.sh}
uses a temporary loopback server and can resolve dependencies. The
journal route \texttt{tools/replay\_offline.py} instead invokes
identical native audit logic, replacing only Phase 4 HTTP transport with
the function behind that endpoint. It copies the capsule into a new
external disposable directory, checks all 190 original manifest entries
before and after, blocks socket connect/bind and provider construction,
and uses only archived cache hits. It never sets the maintenance
manifest-bypass variable. Audit reports are copied out before the
original transactional report bytes are restored for the final manifest
check. Do not point the tool at production state or an existing output
directory.

Example using cached dependencies, with no credential environment
inherited:

\begin{verbatim}
/usr/bin/env -i HOME="$HOME" PATH=/usr/bin:/bin:/opt/homebrew/bin \
  /absolute/path/to/uv run --offline --no-project \
  --with activegraph==1.10.0 --with numpy==2.4.6 --with scipy==1.17.1 \
  --with pydantic==2.14.2 python journal/jesa/tools/replay_offline.py \
  /absolute/new/disposable/output
\end{verbatim}

Environment needs Python ≥3.11 and the listed packages; exact observed
versions and platform are in the receipt. A cold machine needs
dependency setup before offline replay; this preparation installed no
new TeX runtime. Output includes three audit JSON reports and
receipt.json. A mismatch, missing cache response, blocked network call,
or manifest drift is a failure. Replay establishes reconstruction from
the archive, not provider attestation, power, human validity, or freedom
from pre-seal alteration.

characters + sealed bare system text; user text is unchanged.

seeded. Primary revision pin in Phase 5 is gpt-4.1-2025-04-14; the
Gemini pin is unversioned/descriptive. Phase 3 legacy capture is less
complete than Phases 4--5.

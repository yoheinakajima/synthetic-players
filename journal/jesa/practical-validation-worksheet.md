# Practical validation worksheet

This checklist is derived from the limits demonstrated by one fixed panel; it is not a validated universal procedure.

1. Name the intended inference: marginal resemblance, fixed-panel composition, prompt-indexed treatment response, latent-person effect, or human causal accuracy.
2. State the target population or fixed prompt set. Declare a generator and sampling rule before generalizing to personas beyond that set.
3. Specify the intervention and every text/format/environment change bundled with it. Keep wording, position, payoff role, and displayed label distinct.
4. Name the independence unit and nested structure. Calls, seats, and rounds are not automatically subjects.
5. Select uncertainty and test families prospectively. Explain what each prior/bootstrap conditions on; check whether sparse-cell gates can attain the chosen threshold.
6. Show what validation passage leaves unidentified, including a response interval and an assay-sensitivity check appropriate to the target.
7. Archive exact instructions, requested/returned model identities, provider routes, timestamps, parser/retry rules, invalidations, and amendments. Check endpoint drift without assuming a model label guarantees stability.
8. Keep procedural reconstruction, construct validity, power, and human validity separate. Preserve failed predictions and amendments; report post-adjudication analyses with their chronology.
